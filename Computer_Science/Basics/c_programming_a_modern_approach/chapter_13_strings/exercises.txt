c) printf("%s", '\n'); => incorrect, %s expects char * string, but got character ''
d) printf("%s", "\n"); => correct, %s expects string, got string
e) printf('\n'); => incorrect, printf expects char *, got character ''
f) printf("\n"); => correct, printf expects char * "" and got it
g) putchar('\n'); => correct, expects char and got it
h) putchar('\n'); => incorrect, expects '' not ""
i) puts('\n'); => incorrect, expects "" not ''
j) puts("\n"); => incorrect, puts() put \n automatically, so this prints \n two times
k) puts(""); => correct
